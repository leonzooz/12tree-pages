L1 L2 L3 L4 徽章 = 這個工位被哪幾條 lane 走過（* = 有條件）
四個直行，起點在最左，流程往右推進；每行內部由上往下。站位對齊 agent 名冊的五個分組（決策／研究／生產／品管／管控）：
行 1 決策鏈（lane 無關）Y0 資料源 → scanner → appraiser⛨ → contract⛨ → director⛨。
行 2 並行工位：這兩位橫向貼齊行 1 的對手，不是行 1 的下一步。archaeologist 與 scanner 並行（一個挖歷史、一個掃現況，共同餵鑑定）；interrogator 與 appraiser 對打（出價 → 攻擊 → 打回重估），是迴路不是關卡。
行 3 產線：director 依 lane 的 emit schema 決定進場點 —— L2·L4 進總編、L3 進設計、L1 完全不進押注漏斗（gate 是「入圍即做」），scanner 掃完走頂部通道直通文案。
行 4 文案 + 品管管控：copywriter 吃總編的產物規格、不吃 design artifact，所以與設計並行；reviewer⛨ → qa⛨ → investigator（追因）→ undertaker（歸檔）。漂移與資源效率讀數歸 director，因為那是調度層的資源問題。
灰點線＝換行與 lane 分岔（結構性接續），紅虛線＝反向線（逼問打回、審查退回、追因回寫、歸檔回等待名單）。
頂部 Agent 列表：點擊後開啟模型配置；圖面節點仍可直接點擊查看派工內容。

Overall Status · 熔斷規則

黃燈 — 允許繼續執行，但暫時限制探索任務。若連續兩次低於閾值，Coordinator 進入熔斷檢查。

立即阻擋

  • 任何修改硬邊界的 action
  • 未授權 merge / deploy
  • 預算或時程紅線被突破

黃色限制

  • Goal Alignment < 70
  • Resource Efficiency < 0.6
  • 新增 / 完成比 > 1.8
  • Owner interruption rate 過高

紅色熔斷

  • Goal Alignment < 50
  • Resource Efficiency < 0.4
  • 核心任務佔比 < 30%
  • 越權嘗試短時間多次出現

送入本地 queue，不直接改 repo。
